# AURA CORE // Agency Showcase & High-End Software Engineering

Ajansımızın resmi vitrin web sitesi.

## Özellikler
- **Next.js 15 (App Router, React 19, TypeScript)**
- **Anti-Slop Lüks Tasarım:** Obsidyen koyu tema, cam kartlar, asimetrik bento gridler
- **Framer Motion:** 60 FPS pürüzsüz mikro animasyonlar
- **Canlı Proje Vitrini:** Easy VIP Transfer & Autonomous Lead Hunter vaka çalışmaları
- **İnteraktif ROI Simülatörü:** Sektör bazlı zaman & ciro simülasyonu
- **Notion CRM & WhatsApp Entegrasyonu:** `/api/lead` uç noktası

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```
Tarayıcınızda `http://localhost:3000` adresini açın.
